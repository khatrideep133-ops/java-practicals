MINIBANK — SEPARATE PART B PRACTICALS (01–14)

Each Practical_XX folder contains its own Java source file and README.txt.
All programs are independent and can be compiled/run separately.

Recommended: JDK 17+
Windows PowerShell example:
    cd Practical_01
    javac Practical01.java
    java Practical01

Some practicals create small output files in their own current working directory when run.
